## Core Patterns

- **Two Skis Alignment**: Two-Skis Principle: keep the local sentence subject (Ski 1) tightly parallel with the overarching paragraph theme (Ski 2). Forbid mid-paragraph subject jumping.
- **Practical Application**: Deep module explanations, preventing developer vertigo during complex RFC reviews.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
